## Galileo v0.9.06alpha

Alpha pre-release. Please try it and report problems, but **do not use it for production imaging yet.**

Changes since v0.9.05alpha.

- **Catalog images:** the downloadable image pack now includes the large click-to-enlarge images, which are read from the local cache instead of a live survey server.
- **Fixes:** What's Up Tonight's day/night band is centred on mid-night again, and the Star Atlas no longer shows an empty sky on a fresh Linux install.
