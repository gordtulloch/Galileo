## Galileo v0.9.03alpha

Alpha pre-release. Please try it and report problems, but **do not use it for production imaging yet.**

Changes since v0.9.02alpha.

### New

- **Switches page works with power boxes and relay boards, over INDI and Alpaca.** Connect a device and the page shows its ports grouped by type (DC, USB, dew heaters, adjustable outputs) with an On/Off button per switchable port, a duty setting for each dew heater, a voltage setting for regulated outputs, and a Readings box. The INDI and Alpaca Switch adapters were empty stubs before; they now read the device and write to it.
- **WandererBox plugin** (Galileo-Plugins repository): profiles for the Wanderer Astro WandererBox Pro V3, Plus V3 and Dew Terminator, using the vendor's own port names. Plugins can now describe a power box whose INDI driver does not follow the standard interface.
- **Plugins install, update and remove in place.** No restart needed: the sidebar, menus and panels update immediately, and the old version is put back if the new one fails to start. Marketplace tiles show an **Update available** tag and an **Update** button.
- **Plugins can declare dependencies** (`requires` in `plugin.toml`), installed into the plugin's own folder and rolled back if any cannot be resolved.
- **Mount page:** new **Set Park Position** and **Set Home Position** buttons; Rate is now a level from 1 (slowest) to 9 (fastest) and the Imaging page's nudge Speed uses the same scale; all buttons are one size.
- **Focus screen:** Optics and Camera selectors, the focuser associated with the selected Optics, the camera's name, and editable Gain and Offset.

### Fixed

- **Windows crashes (access violation) while slewing or panning the Star Atlas, and some time after a slew.** Worker threads updated the UI from the wrong thread and used a Windows event loop that was unsafe there. Fixed in many places. The cause is fitted to crash traces, not confirmed; if it still crashes, `faulthandler.log` will say.
- **N/S/E/W jog buttons moved an INDI LX200 OnStep mount far too slowly** because the numbered slew rates were never selected.
- **The Home button did nothing on INDI mounts with no homing sensor** (such as OnStep); it now sends the command the driver offers.
- **Schedule: deleting an entry no longer crashes** when the entry is already gone.
- **Galileo failed to start on databases that had applied the old `031_add_focuser_mode` migration.**
- **The splash and About box showed a stale version**, and switching Observatory or Pier no longer shows the full branded splash.
- **INDI log messages now name the server that sent them**, and connection and exposure errors no longer quote another device's message.

### Changed

- **Sessions: Run starts immediately** and no longer adds the session to the Schedule. If a scheduler-started session is running, Run stops it and starts the new one. Run still refuses while the safety monitor reports unsafe conditions.
- The application log no longer records database SQL statements, and now shows the jog rate number.
- The top bar's "Session camera" text is gone because it pushed the current-target indicator off screen.
- The Mount page's "Settings: None" row is removed.

### Installers

Windows x64, macOS Apple silicon, Linux x86_64 and Linux ARM64 (AppImage, including Raspberry Pi 5). **There is no longer a macOS Intel installer** because GitHub retired its Intel build runners; Intel Mac users can install from source.

### Under the hood, not usable yet

The Connect Link listener (encrypted, pairing, plugin routes, event stream) is in the code as foundation for the planned NodeConnect, MobileConnect and WebConnect plugins. **None of those plugins exist yet**; there is nothing to install or test for them. Their requirements and design documents were written and revised during this period.
