## Galileo v0.9.03alpha

Alpha pre-release. Please try it and report problems, but **do not use it for production imaging yet.**

### What's new

- **Switches page now works with power boxes and relay boards, over INDI and Alpaca.** Connect a device and the page shows its ports grouped by type (DC, USB, dew heaters, adjustable outputs) with live readings. The INDI and Alpaca Switch adapters were empty stubs before; `set_switch` now reaches the device.
- **WandererBox support.** The new WandererBox plugin (in the Galileo-Plugins repository) adds profiles for the Wanderer Astro WandererBox Pro V3, Plus V3 and Dew Terminator. Plugins can describe a power box whose INDI driver doesn't follow the standard interface.
- **Plugins can declare dependencies.** `requires = [...]` in `plugin.toml` is installed per plugin when the plugin is installed.
- **Sessions: Run starts immediately.** It no longer adds the session to the Schedule.
- **Top bar:** the "Session camera" text is gone because it was pushing the current-target indicator off screen.

### Under the hood, not usable yet

The Connect Link listener (encrypted, pairing, plugin routes, event stream) is in the code as foundation for the planned NodeConnect, MobileConnect and WebConnect plugins. **None of those plugins exist yet**; there is nothing to install or test for them.

### Known issues

- In-place plugin updates are not implemented. Remove and reinstall instead.

### Install

Download the installer for your platform from the assets below: Windows x64, macOS (Apple silicon only; there is no Intel Mac installer), Linux x86_64 and Linux ARM64 (AppImage, including Raspberry Pi 5).
