## Galileo v0.9.04alpha

Alpha pre-release. Please try it and report problems, but **do not use it for production imaging yet.**

Changes since v0.9.03alpha.

- **Headless engine:** `galileo --engine` runs devices, safety monitoring and the watchdog without the desktop; `--status` reports on it. The desktop can optionally hold its devices in the same device service (Options > Equipment).
- **Equipment pages:** the mount, focuser, rotator, weather, dome, switch, filter wheel, flat panel and auxiliary pages were reworked internally; behaviour should be unchanged.
- **Connect Link and NodeConnect groundwork:** replication core, pairing and push hints for the NodeConnect plugin (shipped separately).
