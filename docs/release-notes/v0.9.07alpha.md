## Galileo v0.9.07alpha

Alpha pre-release. Please try it and report problems, but **do not use it for production imaging yet.**

Changes since v0.9.06alpha.

- **Equipment > Control Panel:** now a full INDI Control Panel like EKOS, with a tab per device and per property group.
- **Imaging and Library:** faster INDI camera downloads, much faster SFTP image downloads, multi-select delete in Library > Images, and Seestar frames are now calibrated rather than treated as precalibrated.
- **Solve:** polar alignment starts where the mount points, turns 15° between frames and waits for the mount to settle; new End Alignment button; Stop no longer breaks later runs. Mosaics and Auto-Centre are more reliable.
- **Remote control:** the phone, tablet and browser surface gains full polar alignment, guide-star selection, session estimates and node health.
- **New:** View Log window, and a Support Us dialog on quit (can be switched off).
