## Galileo v0.9.05alpha

Alpha pre-release. Please try it and report problems, but **do not use it for production imaging yet.**

Changes since v0.9.04alpha.

- **Remote control groundwork:** the Control Surface now offers sky and framing, plate solving, guiding, session history and the scheduler queue, plus frame previews for remote front ends.
- **Fixes:** a crash after switching Observatory or Pier, a plugin reinstall failing on Windows, and INDI connect errors that now name the serial port when the driver is silent.
