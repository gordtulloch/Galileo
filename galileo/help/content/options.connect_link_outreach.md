# Outreach

Lets visitors at a star party watch the live image on their own phones. An outreach event is **off until you open it**, lasts the time you set, and then ends by itself. While it is open, visitors join the guest Wi-Fi, scan a code and see the image from the Piers you offer; they cannot control anything, and they never see the file's details (location, camera, settings). Nothing about an event is saved: closing it, turning Connect Link off or restarting Galileo ends it for everyone. Connect Link must be turned on first (Options > Connect Link).

## Event duration

How long the next event lasts when you press **Open event**, 5 minutes to 24 hours. It starts from the default duration you save below.

## Open event

Starts an event for the time in the box beside it. It will not open unless Connect Link is running, an allowed network is set, at least one Pier is offered, and every ticked surface says it is ready; the message says which is missing. The codes to show visitors appear under **Event display**.

## Extend

Adds 30 minutes to the open event.

## End event

Ends the event now. Every visitor is disconnected and their access and the event's secret stop working.

## Eject all guests

Disconnects every visitor now but leaves the event open; they can join again with the codes.

## New secret

Makes a new secret and new codes. Codes already shown stop working for new visitors; visitors already watching are not affected. Use it if a code has been shared beyond the people you meant.

## Event display

The codes to put on a screen or a sign while the event is open: first one for the guest Wi-Fi (it holds the passphrase only if you set one), then one for each surface that is ticked.

## Wi-Fi network name

The name of the guest Wi-Fi network visitors join. It is shown in the Wi-Fi code.

## Wi-Fi passphrase

The guest Wi-Fi's password, if it has one. It is kept in the system keychain, never in Galileo's settings, and is used only to build the Wi-Fi code. Leave the box blank to keep the one already saved.

## Allowed networks

The address range of the guest Wi-Fi, for example `192.168.50.0/24`; separate several with commas. Only devices in these ranges can join, and a visitor seen from anywhere else is disconnected. Only private ranges are accepted, so nothing on the internet can reach an event.

## Default duration

How long an event lasts when you open it without changing the time (5 minutes to 24 hours).

## Guest limit

The most visitors at once. Others are told the event is full and can try again.

## Image size

The longest side of the image sent to visitors, in pixels. Smaller images are quicker on a busy Wi-Fi. They are always sent without any file details.

## Image quality

The picture quality of the image sent to visitors (30 to 80). Lower is quicker and rougher.

## Piers offered

Tick the Piers visitors may watch. Visitors see only the Observatory and Pier name.

## Surfaces

The ways visitors can join, supplied by installed plugins (for example a phone app or a web page). Tick the ones to offer. With none installed the list is empty.

## Save

Saves the options above.
