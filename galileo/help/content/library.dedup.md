# Dedup

Dedup finds duplicate files in the Library: files with identical content (the same hash), such as the same frame copied or imported twice. Duplicates waste disk space and double-count frames in stacks. Each group of identical files is listed together, with the file name, object, date, filter, exposure, type and full path. You can safely remove all but one copy of each group.

Press **Refresh Duplicates** to scan, review the groups, then **Delete Duplicate Files**.

## Refresh Duplicates

Scans the catalog for files with identical content and lists each group. A progress window appears for large catalogs and can be cancelled.

## Delete Duplicate Files

Removes the extra copies in the listed groups, keeping one of each. It is greyed out until duplicates have been found, and asks you to confirm first.

## Duplicates

The list of duplicate groups. Click a column heading to sort it.
