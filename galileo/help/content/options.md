# Options

Options holds the settings for each part of Galileo, one page per area, in the same order as the main menu. Settings that depend on your equipment (Focus, Solve) are saved per **Pier**, so each telescope keeps its own; others (Imaging, Planning, Library) apply to the whole application.

Choose an area from the menu on the left. Changes take effect as described on each page — some apply as you change them, others when you press **Save**.
