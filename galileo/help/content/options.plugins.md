# Plugins

Plugins add features to Galileo — for example the variable-star planning and photometry tools. This page installs, enables, disables and removes them.

The **Installed** tab lists what you have, with each plugin's version, whether it is first-party or third-party, and its author. The **Marketplace** tab lists plugins available to download.

Most changes take effect after you restart Galileo; a banner reminds you when that is needed.

## Install from file

Installs a plugin from a ZIP file on your computer. Only install plugins from sources you trust: a plugin runs inside Galileo with the same access you have.

## Enabled

Untick to disable a plugin without removing it, or tick to enable it again. Takes effect after a restart.

## Remove

Uninstalls the plugin after asking you to confirm; this cannot be undone. If the plugin's screen was already loaded, restart Galileo to clear it completely.

## Refresh

Fetches the current list of available plugins from the marketplace again.

## Install

Downloads and installs this plugin from the marketplace. It is then shown as Installed; restart Galileo to start using it.
