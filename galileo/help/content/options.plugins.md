# Plugins

Plugins add features to Galileo — for example the variable-star planning and photometry tools. This page installs, enables, disables and removes them.

The **Installed** tab lists what you have, with each plugin's version, whether it is first-party or third-party, and its author. The **Marketplace** tab lists plugins available to download.

Installing, updating and removing a plugin takes effect straight away — its screens appear in (or leave) the sidebar and menus without restarting Galileo. Only turning a plugin on or off, or a removal that Windows cannot finish while the plugin's files are in use, waits for a restart; a banner says when.

A plugin whose marketplace version is newer than the one you have shows an **Update available** tag, on its tile here and in the Marketplace.

## Install from file

Installs a plugin from a ZIP file on your computer. Only install plugins from sources you trust: a plugin runs inside Galileo with the same access you have.

## Enabled

Untick to disable a plugin without removing it, or tick to enable it again. Takes effect after a restart.

## Update

Appears on an installed plugin's tile, next to the **Update available** tag, when the marketplace has a newer version. Downloads it and swaps it in without restarting Galileo: the old version is unloaded, the new one started, and its screens are rebuilt. If the new version fails to start, the version you had is put back.

## Remove

Uninstalls the plugin after asking you to confirm; this cannot be undone. The plugin's screens leave the menus at once; if its files are still in use, Galileo deletes them the next time it starts.

## Refresh

Fetches the current list of available plugins from the marketplace again.

## Install

Downloads and installs this plugin from the marketplace. It is then shown as Installed and is ready to use immediately.
