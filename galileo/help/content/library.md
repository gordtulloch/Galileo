# Library

The Library is Galileo's catalog of all your astronomy image files. Galileo files every frame you capture, plus any you import, in an organised repository folder and keeps a database of what each file is — its object, filter, exposure, date, telescope and camera. The Library screens let you browse that catalog and look after it.

- **Images** — every file, sorted into a tree by object, date or filter.
- **Sessions** — frames grouped into imaging sessions (one object, one night, one setup), with their calibration frames linked, ready to calibrate and stack.
- **Mappings** — fix inconsistent names in FITS headers.
- **Dedup** — find and remove duplicate files.
- **Merge Objects** — combine two names that are really the same object.
- **Cloud** — back up and synchronise the repository with cloud storage.

Where the repository lives, and cloud, compression and telescope settings, are set in Options › Library.
